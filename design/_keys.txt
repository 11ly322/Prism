常见问题
Windows 提示「未知发布者」／SmartScreen 拦截
安装包未做代码签名。点「更多信息」→「仍要运行」即可。程序不联网、不需要管理员权限。
macOS 双击没反应
先在终端执行
chmod +x "启动 Prism.command"
；若提示无法验证开发者，右键 → 打开。
Linux 启动报缺 tkinter
那是系统没装 Tk：
sudo apt install python3-tk
（Fedora 用
python3-tkinter
）。
完整版和看图版有什么区别
看图版没有修图面板，只保留浏览、缩放、旋转、幻灯片、胶片条与网格，体积更小；其余格式支持与渲染性能完全一致。
为什么没有全屏
F11 全屏在部分机器上显示不全，权衡后已在早前版本移除，而不是留一个半坏的功能。

如何安全绕过 SmartScreen
安装包未做代码签名，所以 Windows 会提示「已保护你的电脑」。先校验文件，再决定是否运行：
在 PowerShell 里校验 SHA-256：
Get-FileHash .\Prism-Setup-8.6.2.exe -Algorithm SHA256
与页面上的 SHA-256 逐位比对。
一致 → 双击安装包，点弹窗里的「更多信息」。
确认发布者是「未知发布者」且哈希已核对无误后，点「仍要运行」。
校验不一致 → 立刻删除，重新下载。
如果你不希望运行未签名程序：用上面的便携版 zip，或直接跑源码
python src/Prism.pyw
