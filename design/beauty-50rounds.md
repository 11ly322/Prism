# 美颜 50 轮迭代记录（9.15.8）

目标：在不引入模型、不联网的前提下，把 Prism 的人像美化从“能生效”推进到
“不同肤色都稳、斑点不越修越亮、背景不误伤、预览与导出一致”。

## 质量台架

`tools/beautybench.py` 用可复现的合成人像（浅肤 / 中肤 / 橄榄 / 深肤、低光、色偏、
12MP 大图）度量：

- 人脸外像素变化（应为 0）
- 肤色覆盖率与人脸检出数
- 颊部明暗标准差（肤色均匀度）
- 高频纹理保留比（不能磨成塑料）
- 暗斑与周围皮肤的对比度（应下降，且不能变成亮斑）
- R/G/B 裁切增量
- 低光提亮量
- 12MP 全尺寸耗时

基线取 9.15.7 发布版；最终数据见 `design/beauty-bench-final.json`。

| 指标 | 9.15.7 | 9.15.8 |
| :--- | ---: | ---: |
| 人脸检出 | 4/4 | 4/4 |
| 人脸外变化 | 0.018 | 0.000 |
| 肤色占背景比例（越低越好）| 0.290 | 0.143 |
| 颊部标准差（浅/中/橄榄/深）| 9.72 / 11.25 / 11.58 / 15.11 | 6.49 / 5.52 / 5.40 / 4.25 |
| 高频纹理保留 | 0.709 | 0.664 |
| 暗斑对比度（修前→修后）| 16.48 → -3.61（过亮）| 16.48 → 2.14 |
| 低光脸部亮度（提亮 65）| 107.4 → 110.9 | 107.4 → 125.8 |
| 12MP 全尺寸 | 4.95 s | 6.23 s |

说明：斑点对比度从“负值”变为接近 0 的正值，表示不再把暗斑修成亮斑；
纹理保留比略降，是因为 9.15.8 的中频压平更积极，但仍保留约三分之二高频。

## 验收

- `tools/beautybench.py`：四肤色全部检出；人脸外 0 变化；斑点不再修成亮斑；
  低光提亮 18.4；12MP 6.23 s。
- `tools/beautycheck.py`：全部通过；新增材质/斑点/边界/预设/预览一致性断言。
- `tools/runall.py --fast`：按发布脚本要求全绿。
- 网站与安装器版本号统一为 9.15.8。

## 已知取舍

- 没有关键点模型，侧脸/强遮挡仍可能跳过；这是有意的“宁可不动”。
- 12MP 全尺寸比 9.15.7 慢约 1.4 s，换来更稳的肤色/斑点/背景处理；预览路径不受影响。
- 纹理保留比略低于 9.15.7，但斑点与色块处理更积极；低档位仍刻意做轻。
