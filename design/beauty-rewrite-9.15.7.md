# 9.15.7 美颜系统重写

## 目标

解决三个具体问题：入口分散、预设按钮被裁切、同一次美颜重复计算多张蒙版/人脸框。

## UI

- 只有一个「人像美化」分区，位于「调整」分类。
- 预设 2×2：自然 / 人像 / 网红 / 素颜；长英文/日文名称不会被裁切。
- 分区顺序：预设 → 皮肤 → 修复 → 轮廓 → 分区强度。
- 与「镜头与胶片」分离：镜头畸变、胶片模拟不再和人像滑杆混在一起。
- `工具 → 人像美化…` 仍可直接定位到该分区。

## 算法

```
肤色蒙版（一次）
  └─ 人脸框（一次，只有需要脸部的效果才跑）
       └─ 瘦脸/大眼（先变形）
            └─ 重算肤色蒙版（一次）
                 ├─ 磨皮/均匀：同一套低频分离 + 共享边缘权重
                 ├─ 祛斑
                 ├─ 眼周 / 牙齿 / 唇色
                 └─ 提亮 / 去油光 / 冷暖 / 柔光
```

- 去掉全尺寸中值滤波；均匀肤色改为更大尺度的低频分离。
- 边缘权重和分区权重只生成一次，后续只做蒙版乘法。
- 预览缓存键和导出一致性保持不变。

## 验证

- `beautycheck`：单独效果、中性值、肤色边界、祛斑、瘦脸、多人合影、
  预览 == 导出、预设强度全部通过。
- `uicheck`：图片信息菜单、工具区去重、美颜预设四种语言不截断、
  分类互斥与回切。
