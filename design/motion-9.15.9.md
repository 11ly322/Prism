# 动效与点击反馈（9.15.9）

## 目标

在不改变任何业务行为的前提下，让鼠标反馈从“颜色瞬切”变成连续、可感知但不拖沓的过渡；
所有动效仍由设置里的唯一开关 `motion` 控制。

## 时间参数

| 动作 | 时长 | 曲线 |
| :--- | ---: | :--- |
| 悬停渐变 | 150 ms | ease-out cubic |
| 按下 | 90 ms | ease-out cubic |
| 松开回弹 | 180 ms | ease-out cubic |
| 点击涟漪 | 300 ms | ease-out quint |
| 图标悬停 / 按压 | 135 / 105 ms | ease-out cubic |
| 原生按钮按下 / 松开 | 85 / 170 ms | ease-out cubic |
| 设置开关 | 170 ms | ease-in-out cubic |
| 状态栏提示淡回 | 45 ms 保持 + 240 ms | ease-out cubic |
| 预览脉冲 | 360 ms 三角波 | ease-in-out cubic |

## 组件

### `_QpeRoundButton`

- `_hover_t`、`_press_t` 连续浮点值，不再用固定帧数。
- 悬停时文字上浮 1px；按下再下沉 2px，松开回弹。
- 点击时在点击坐标生成一圈主题色 ripple，淡出后自动清理。
- `destroy()` 取消 hover / press / ripple / feedback 四类 `after` 任务。
- `MOTION_ENABLED` 为假时所有状态立即落到终值，不创建动画循环。

### `_QpeSwitch`

- 轨道 + 圆钮自绘，点击 / 空格 / 回车切换。
- 变量 trace 同步外部 `set_motion()` 调用；设置窗口销毁时 `detach()` 移除 trace。
- 关闭状态下轨道仍可见，避免浅色主题下与卡片同色。

### 原生按钮与工具条图标

- `_wire_press()` 用短缓动混合底色与前景色，关闭动效时不改色。
- 工具条 Canvas 图标按 hover / press 两个连续值混合，松开命令照常执行。

### 状态栏 `_flash`

- 先保持强调色 45ms 让用户看见，再用 240ms ease-out 淡回 `FG_DIM`。
- 关闭动效时直接落回默认色。

## 开关语义

设置 →「动效与反馈」：

- **开**：悬停渐变、按压回弹、点击涟漪、状态淡出、图标渐变、开关缓动。
- **关**：所有控件立即响应；按钮命令、快捷键、业务状态完全不变；不做任何动画。

## 回归

`tools/motioncheck.py` 覆盖：

1. 连续悬停与终值。
2. 按压值、回弹与涟漪生命周期。
3. 原生按钮按下 / 松开颜色。
4. 工具条图标按下反色。
5. 自绘开关关闭、持久化、重新开启。
6. 关闭后无按压、无涟漪。
7. 状态提示从强调色开始并在 240ms 后回落。
8. 设置持久化与主题切换。
