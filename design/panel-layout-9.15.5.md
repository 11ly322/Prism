# 9.15.5 右侧修图栏排版

## 结构

```
┌ 固定顶部 ───────────────┐
│ 修图                     │
│ 直方图                   │
│ 人像 / 胶片 / 镜头 / 美颜 │
│ 人脸/代理状态             │
├ 滚动调整区 ─────────────┤
│ 基本                     │
│ 镜头 · 胶片 · 人像        │
│ 人像美化高级              │
│ 曲线 / HSL / 细节 / 效果  │
│ 局部 / 预设 / 快照        │
│ 工具（默认收起）          │
├ 固定底栏 ───────────────┤
│ 撤销  重做  对比  保存    │
└─────────────────────────┘
```

## 关键尺寸

- 面板默认宽度：260px（旧默认 238px 自动迁移），可拖动左缘改宽。
- 顶部固定区包含标题、直方图、四个快捷入口和状态行。
- 底栏固定高度 42px，只放四个高频动作。
- 「工具」区默认折叠，内部为两列操作网格 + 历史记录列表。

## 设计取舍

- 直方图和常用动作常驻，不随长面板滚动；调整内容仍保留原滚动位置。
- 工具/历史不删除，只收纳，避免首屏出现十几行功能按钮。
- 分区仍使用卡片和折叠箭头，标题加粗提高扫描性；不引入会改变布局尺寸的动效。
- 滚动条改为自绘细条，跟随主题配色。
