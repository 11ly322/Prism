# 9.15.6 右侧修图栏：分类工作区

## 结构

```
┌ 固定顶部 ───────────────────┐
│ 修图                         │
│ 直方图（含暗/亮/均读数）      │
│ 调整  颜色  细节  效果  预设  工具 │
│ 人脸/代理状态                 │
├ 当前分类内容（可滚动）────────┤
│ 调整：基本 / 镜头·胶片·人像 / 人像·高级 │
│ 颜色：曲线 / HSL / 颜色分级    │
│ 细节：细节                     │
│ 效果：效果 / 局部调整          │
│ 预设：预设 / 快照              │
│ 工具：批量/改名/分屏/网格/历史  │
├ 固定底栏 ───────────────────┤
│ 撤销   重做   对比   保存      │
└─────────────────────────────┘
```

## 关键决策

- **不再把十几个分区堆在一条长滚动列表里**。六个分类标签一次只展示一组，
  首屏高度稳定，切换分类不重建控件，滑块/折叠状态保留。
- 顶部直方图和分类标签固定；底栏四个高频动作固定；只有当前分类内容滚动。
- 调整分类保留原「基本 / 镜头 · 胶片 · 人像 / 人像 · 高级」的完整控件。
- 工具与历史集中到「工具」分类，不再占用调整区的首屏。
- 面板默认 260px，可拖宽；分类标签为自绘按钮，选中态使用主题强调色。
- 自绘细滚动条跟随主题，浅色主题不再出现白色系统滚动槽。

## 尺寸

- 面板默认宽度：260px（旧默认 238px 自动迁移）
- 顶部分类标签：6 个等宽自绘按钮
- 底栏高度：42px
- 分类容器互斥显示，同一时间只挂载一个分类
