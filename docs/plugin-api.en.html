Localized text (9.6.0)

name, description and PARAMS.label may be plain strings, or objects like {"zh": "...", "en": "...", "ja": "..."}. A missing language falls back to Chinese. Third-party plugins that only provide a string keep showing it as-is. Values in options are passed to run() unchanged and are not translated (the displayed option is the value itself).

network / writes_files are shown in the plugin window purely to improve transparency; they are not enforced constraints — plugins still run with full permissions.

Parameter memory (9.4.0)

Prism remembers the parameters each plugin used last time, by PLUGIN.id, in plugin_params inside Prism_settings.json; they survive a restart. The next run of the same plugin restores them automatically.

  • Old values outside the range are clamped to the new min/max.
  • Removed options fall back to the new default.
  • A changed id means a different plugin; the old parameters are not applied.
  • "Restore defaults" in the result window clears this plugin's memory.

Plugins need to write no code for this; the defaults declared in PARAMS are still the values used on the first run.

  • Startup flag --plugin-dev: the log records each plugin's load time and execution time, the UI shows

Error log format

Written uniformly to logs/plugins.log (in the same directory as Prism_settings.json):

[2026-10-18 14:02:11] plugin=skin_smooth api=2 run failed: ValueError: 参数 '强度' 超出范围 (got 120, max 100)

Field order: time, plugin id, api version, stage (load / run / reload), exception type, first line of the message. Under --plugin-dev, the full traceback is appended as well.

Enabling / disabling

Rename plugin.py to plugin.py.disabled to disable it, and rename it back to enable it. The plugin window lists disabled items.
