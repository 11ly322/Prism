安装插件

三种方式，效果一样：

  1. 插件市场（9.5.0）：插件窗口 →「插件市场」→ 选一个 →「安装」/「更新」。
  2. 从网址安装：插件窗口 →「从网址安装…」→ 填 .py 的 http(s) 直链，可再填 SHA-256。
  3. 放进目录：把 .py 丢进插件目录（插件窗口顶部显示完整路径），点「重新扫描」或等 1.5 秒热重载。

临时停用：把 xxx.py 改名成 xxx.py.disabled，插件窗口会显示成「启用 xxx」按钮。

安装只解决「下载到的东西没被改过」（SHA-256），不解决作者可信不可信。 插件声明的 network / writes_files 会在确认框里显示，但那只是作者自己填的声明。

发布插件到市场

官方市场读 plugins/index.json。从写插件到用户能在市场里看到，一共六步：

PLUGIN 里 id 唯一、api: 2，network / writes_files 如实填写； PARAMS 用 slider / select / checkbox / text。 用 --plugin-dev 启动可以看 logs/plugins.log 里的加载/执行耗时。

  1. 写插件：单文件放 docs/plugins/<文件名>.py，文件名用 ASCII。
  2. 本机自测：把 .py 放进插件目录（插件窗口顶部有完整路径），运行、调参、另存；
  3. 算 SHA-256（必须与文件逐字节一致）：
   Get-FileHash docs\plugins\myplugin.py -Algorithm SHA256
  1. 在 plugins/index.json 里加一项（plugins 数组，schema 1）：
   {
     "id": "myplugin",
     "name": {"zh": "我的插件", "en": "My plugin", "ja": "マイプラグイン"},
     "version": "1.0",
     "api": 2,
     "author": "你的名字",
     "description": {"zh": "一句话说明", "en": "One line", "ja": "ひとこと"},
     "network": false,
     "writes_files": false,
     "url": "https://11ly322.github.io/Prism/plugins/myplugin.py",
     "sha256": "<上一步的 64 位小写十六进制>",
     "source": "docs/plugins/myplugin.py"
   }

url 的文件名必须和 source 一致；官方清单固定用 Pages 地址。

  1. 生成索引并自检：
   python tools/make_plugin_index.py          # 更新 README 三语表格 + docs 副本
   python tools/make_plugin_index.py --check  # 必须通过

它会校验 SHA-256、三语字段、id 唯一、api 与 URL，并确认 docs/plugins/index.json 与仓库版本一致。发布门禁也会跑这一步。 docs/plugins/index.json 一起提交。合并后 Pages 部署约 1 分钟生效； 应用里点「刷新」就能看到新插件，已装旧版的用户会看到「可更新」。

  1. 提 PR：源码、plugins/index.json、plugins/README.md（三语三份）、

更新一个已发布的插件：改 docs/plugins/ 源码 → 版本号 +1（PLUGIN.version 与 index.json 的 version 同步）→ 重算 SHA-256 → 跑生成脚本。市场按版本号判断可更新。

自己维护一份市场（不进官方仓库）：

  • 把同样格式的 index.json 放到任意 http(s) 静态托管（每个条目仍必须带 SHA-256）；
  • 用户在启动 Prism 之前设置环境变量 PRISM_PLUGIN_CATALOG 指向它；
  • 不需要改代码，也不需要重新打包。

安全底线：清单本身不执行任何代码；安装时只解析 AST、强制比对 SHA-256， 确认后才写盘。

参数会被记住（9.4.0）

每个插件的参数按 id 存在设置文件里（plugin_params）。下次运行同一个插件时自动恢复上次的值， 包括重启 Prism 之后。点结果窗口的「恢复默认」会清掉这份记忆。

  • 插件改了参数范围：超范围的值会被夹到新范围内。
  • 插件删了某个选项：失效的选项回落到新的默认值。
  • 插件换了 id：等于一个新插件，旧记忆不会套上去。

开发流程

  1. 复制 _template.py 为 myplugin.py（文件名不要以下划线开头，那是给框架文件留的）
  2. 改 PLUGIN / PARAMS / run
  3. 保存，Prism 约 1.5 秒自动重载（插件窗口也能点「重载插件」）
  4. 出错不会崩主程序：写 logs/plugins.log，原图回退

PLUGIN 字段

字段必填说明
id是唯一标识；参数记忆、安装文件名、市场清单都用它。建议 ASCII 字母数字与 - _
name是列表里显示的名字
version建议显示在名字后面；市场用它判断是否可更新
api建议当前支持 1、2；2 是 run(img, **params) 写法

description建议hover 提示里显示
network建议是否联网，如实填写
writes_files建议是否写文件，如实填写

第三方插件怎么放进来

补上 source、url、sha256 与 zh/en/ja 三语名与说明；make_plugin_index.py --check 必须通过。

  • 单文件、只依赖 Pillow 与 numpy（Prism 已带），不要起线程、不要改 Prism 的内部状态。
  • 文件名用 ASCII，id 唯一；不要以 _ 开头。
  • 自己的插件请放用户插件目录（插件窗口顶部有完整路径），不要改安装目录里的自带插件。
  • 想收进官方清单：提 PR 在 plugins/index.json 加一项，并把源码放到 docs/plugins/，
  • 带联网 / 写文件副作用的插件必须在 PLUGIN 里如实声明。

复用函数

_utils.py 提供 preview_then_export / downscale_if_needed / upscale_back / preserve_alpha / split_alpha / to_rgb / clamp_params，不是框架，复制走也行。 preview_then_export(func, img) 最省事：降采样 → 跑 func → 放大回原尺寸 → 贴回 alpha。 导入前需要把插件目录加进 sys.path（见该文件头注释）。
