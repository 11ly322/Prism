# Community / official plugin directory

Prism ships 12 bundled plugins (index in `../README.md`). External plugins can be published in two ways:

1. **Add to the official catalog** `plugins/index.json`: users can browse it in the Plugin marketplace, install with one click, and check for updates.
2. **Keep it outside the repository**: provide an http(s) direct link to a `.py` plus its SHA-256; users install it with Plugins → Install from URL…

The two tables in `plugins/README.md` are generated by `tools/make_plugin_index.py` from the
**plugin sources + index.json**; do not edit the tables by hand.

## Acceptance criteria

- Source must be readable: no binaries, encryption, or obfuscation.
- No network uploads: no network requests and no uploading user images. If a plugin genuinely needs the network, declare it in `PLUGIN.network`.
- Never damage the original image: return a new image, do not overwrite user files. Plugins that write files must declare it in `PLUGIN.writes_files`.
- Declare `api` and keep it within the supported range (1 / 2).
- Fill in `.github/ISSUE_TEMPLATE/plugin-submission.yml` before submitting.

## What a PR for the official catalog must change

1. `docs/plugins/<filename>.py`: the plugin source (ASCII filename).
2. `plugins/index.json`: add one entry — fields are documented in [plugin-api.en.md](../../docs/plugin-api.en.md):
   `id` / `name` (zh/en/ja) / `version` / `api` / `author` / `description` (zh/en/ja) /
   `network` / `writes_files` / `url` / `sha256` / `source`.
3. Run `python tools/make_plugin_index.py --check`; it must pass (it verifies SHA-256,
   the three languages, and that the READMEs and docs copy are current).

The app never executes any code from the catalog; installation only parses the AST and
rejects any SHA-256 mismatch.
