# 社区插件目录（预留）

目前 Prism 自带 9 个插件，还没有外部插件收录。这个目录是给社区插件预留的：
外部作者的作品会以「一个 .py + 一行索引」的形式放在这里，索引记录在下面的表格。

## 收录标准

- 必须能读源码：不接受二进制、加密或混淆过的插件。
- 不联网上传：不得有网络请求，不得把用户图片外传。
- 不破坏原图：只返回新图，不覆盖用户文件。
- 必须声明 api 版本，且与当前支持的版本一致。
- 提交前请按 .github/ISSUE_TEMPLATE/plugin-submission.yml 填表。
